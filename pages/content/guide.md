# 使い方ガイド

**ImageOverlayTool** は、複数の画像を重ね合わせて比較・調整するためのデスクトップアプリケーションです。

## 1. インストール

### ダウンロード

[GitHub Releases](https://github.com/yhmr/ImageOverlayTool/releases) から最新版をダウンロードしてください。

- **Windows**: `.exe` または `.zip` ファイル
- **Linux**: `.AppImage` または `.deb` ファイル

### 動作要件

- Windows 10 以降 / Linux (Ubuntu 20.04+)

## 2. 基本操作

### 画像の読み込み

1. メニューから「画像設定」を選択するか、`Ctrl+I`（macOS: `Cmd+I`）を押します。
2. 画像設定ウィンドウが開きます。「追加」ボタンから画像ファイルを選択してください。
3. 複数の画像を読み込むことで、レイヤーとして重ね合わせて表示できます。

### 画像の操作

- **移動**: 画像をドラッグして位置を調整します。
- **変形**: 四隅のアンカーポイントをドラッグして、パースペクティブ補正（自由変形）が可能です。
- **ズーム**: マウスホイールでステージ全体の拡大・縮小ができます。

### レイヤー管理

- 画像設定ウィンドウでは、画像の一覧表示、ドラッグ＆ドロップによる並び替え、透過度の調整ができます。
- レイヤー順序の変更はリアルタイムにメインウィンドウに反映されます。

## 3. カスタマイズ

### 背景色の変更

キャンバス上を右クリックして、コンテキストメニューから背景色を変更できます。

### 設定の永続化

ウィンドウサイズ、表示位置、背景色、言語設定などは自動的に保存され、次回起動時に復元されます。

## 4. キーボードショートカット

| ショートカット | 動作 |
|---|---|
| `Ctrl+I` / `Cmd+I` | 画像設定ウィンドウを開く |
| `Ctrl+Z` / `Cmd+Z` | 元に戻す |
| `Ctrl+Shift+Z` / `Cmd+Shift+Z` | やり直し |
