# Support

## Contact

- Email: `yhmr.develop@gmail.com`

## What to Include in a Support Request

To reduce turnaround time, include:

- App version
- OS and version
- Reproduction steps
- Expected behavior and actual behavior
- Sample `.iot` file or screenshot (if shareable)
- Exported app logs (if available)

## How to Export Logs

Use "Export Logs" from the menu (shortcut: `Ctrl+Shift+L`) to export log files, and attach them when reporting issues.

## Issue Categories

- Bug report: incorrect behavior, crash, freeze, data corruption risk
- Feature request: workflow improvements, new tools, UI changes
- Store/compliance question: policy, licensing, privacy, support process

## Response Scope

Support is provided on a best-effort basis.  
Critical issues (data-loss or crash-related) are prioritized.
